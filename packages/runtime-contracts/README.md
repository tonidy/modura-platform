# @modura/runtime-contracts

Shared error categories, definitions, and wire types for Modura services.

This package is part of [Modura](https://github.com/tonidy/modura-platform). See the platform README and linked architecture/specification docs for usage and compatibility guarantees.

## Install

```sh
npm install @modura/runtime-contracts
```

The package is published as an ES module with JavaScript and TypeScript declarations.
